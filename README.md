# ApexPlanet - AICTE Web Development Internship

This repository contains practical projects and tasks developed as part of the **AICTE Web Development Internship** at **[ApexPlanet](https://apexplanet.in/)** ([apexplanet.in](https://apexplanet.in/)).

The internship focuses on mastering modern web development foundations, covering HTML5, CSS3, JavaScript (ES6+), responsive design, client-side form validation, dynamic DOM manipulation, and asynchronous REST API integration.

---

## 📌 Projects Overview

The repository showcases progressive learning modules from basic structuring to interactive web applications:

### 1. Simple Webpage (`simple_webpage.html`)
* **Description:** A clean, responsive foundational website demonstrating core web structure and design principles.
* **Key Features:**
  * Semantic HTML5 layout (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
  * Responsive CSS design with navigation and cards.
  * Image handling and external references.
  * Introductory JavaScript DOM interaction (event-triggered alert).

### 2. Contact Form & To-Do List (`contact_form_todo_website.html`)
* **Description:** An interactive utility page combining client-side form validation and a dynamic task tracker.
* **Key Features:**
  * **Interactive Contact Form:** Client-side validation for name length, valid email formatting, and message length with custom status feedback.
  * **Dynamic To-Do List:** Real-time task creation, removal of individual items, empty-state messaging, and live task counter.
  * Responsive CSS Grid and Flexbox layouts.

### 3. Interactive Web Lab (`interactive_web_lab.html`)
* **Description:** An advanced multi-feature web application featuring an interactive quiz and live API consumption.
* **Key Features:**
  * **JavaScript Quiz:** Multiple-choice quiz application with dynamic question rendering, score tracking, answer feedback (highlighting correct/incorrect answers), and restart functionality.
  * **Random Joke Generator (REST API Integration):** Asynchronous data fetching (`fetch` API with `async/await`) using a public REST API (`official-joke-api`), including loading states, error handling, and XSS-safe DOM insertion.
  * Modern card-based UI with responsive CSS Grid.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic markup, forms, and accessibility elements (`aria-label`, `aria-live`).
* **CSS3:** Flexbox, CSS Grid, custom styling, media queries for mobile/tablet responsiveness.
* **JavaScript (Vanilla JS - ES6+):** Event handling, DOM manipulation, form validation, asynchronous API communication (`fetch`, `async/await`), and dynamic component rendering.

## 🚀 Getting Started

To view and run any of the projects locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/OshekharO/ApexPlanet.git
   cd ApexPlanet
   ```

2. **Open in Browser:**
   Simply open any `.html` file directly in your preferred web browser:
   * Double click on `simple_webpage.html`, `contact_form_todo_website.html`, or `interactive_web_lab.html`.
   * Alternatively, use a local development server such as VS Code's "Live Server" extension or Python's HTTP server:
     ```bash
     python3 -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your browser.
